# 사이타마훈련소

푸쉬업·스쿼트 기록, 월별 캘린더, Three.js 캐릭터 성장. 모바일 우선 정적 웹 앱입니다.

- 기본 목표: 각각 50개. 설정에서 각각 변경할 수 있습니다.
- 날짜별 실제 횟수 입력·수정·삭제. 달성 여부는 그 날짜에 저장된 목표로 계산합니다.
- 데이터는 `localStorage`의 `saitama-training:v1`에 저장됩니다. 서버로 운동 기록을 전송하지 않습니다.
- JSON 백업: 내보내기, 유효성 검사, 합치기/전체 교체 미리보기. 합치기는 같은 날짜를 백업 내용으로 교체하고 현재 목표는 유지합니다.
- iOS 홈 화면용 180px 아이콘, Android용 192/512px 아이콘과 웹 앱 매니페스트를 포함합니다.

## 성장 규칙

레벨 1에서 시작하여 **운동한 날 10일마다 1레벨 상승**, 최대 200레벨입니다. 푸쉬업과 스쿼트의 합이 1개 이상이면 운동한 날로 인정하며, 하루에 여러 번 수정해도 하루만 인정합니다. 연속 10일일 필요는 없습니다.

마지막 운동 이후 **기록이 없는 날 10일마다 1레벨 하락**, 최저 1레벨입니다. 과거 기록 사이에 있었던 공백도 적용합니다. 기록한 당일은 미기록일에 포함하지 않습니다. 예: 9월 1일 마지막 운동 후 9월 11일까지 기록이 없으면 −1레벨. 9월 11일 운동을 기록하면 공백은 9일이므로 해당 감소는 취소됩니다. 9월 12일 재개하면 중간에 10일의 공백이 있어 감소가 유지됩니다.

레벨 상승에 필요한 운동 일수의 나머지는 하락해도 유지됩니다. 최고 레벨에서 초과 레벨을 비축하지 않습니다. 기록 수정·삭제·복원 때 모든 과거 이력을 날짜순으로 다시 계산합니다. 기기의 로컬 날짜를 사용합니다.

체격과 근육은 매 레벨 조금씩 변합니다. 주요 단계는 LV. 1 / 10 / 30 / 60 / 100 / 200이며, 60에서 오라, 100에서 불꽃 눈, 200에서 최종 오라가 해금됩니다. 도감 슬라이더로 1~200레벨 외형을 미리 볼 수 있습니다.

## 개발

Node.js 22 이상 권장.

```sh
npm ci
npm run dev
npm run check
```

`npm test`는 기록, 날짜, 백업 검증, 레벨 경계와 감쇠 규칙을 검증합니다. `npm run build` 출력은 `dist/`입니다.

## GitHub Pages

[Vite 공식 배포 방식](https://vite.dev/guide/static-deploy#github-pages)에 따라 저장소의 Settings → Pages → Source를 **GitHub Actions**로 설정합니다. `main` 푸시 때 `.github/workflows/deploy.yml`에서 테스트·빌드 후 배포합니다. PR에서는 검증만 수행합니다.

서비스 경로: `https://wkdeogh.github.io/saitama_workout/`

## 저장과 백업

브라우저/기기/사이트 주소별로 저장 공간이 다릅니다. 브라우저 데이터 삭제 전 JSON을 내보내고, 다른 기기에서는 파일을 가져오세요. 시크릿 브라우저에서는 기록이 유지되지 않을 수 있습니다. 네트워크 없이 앱을 다시 여는 오프라인 캐시는 별도로 제공하지 않습니다.

잘못된 저장 데이터를 감지하면 덮어쓰기를 막고 원본 내보내기와 정상 백업 복원을 제공합니다. 가져오기는 2MB 이하, 지원 버전, 날짜, 정수 횟수와 목표를 검증합니다.

## 이미지

사용자 제공 `pic/` 원본을 보존하고 `public/images/`에서 화면에 사용합니다. 홈 화면 아이콘은 제공된 치비 이미지를 참조해 내장 Imagegen으로 제작했습니다. 생성 원본: `public/icons/app-source.png`. 배포 크기: 32/180/192/512px PNG.

아이콘 프롬프트: "제공된 치비 사이타마의 대머리 얼굴·무표정한 눈·빨간 주먹·노란 옷·흰 망토를 유지한 정사각형 앱 아이콘. 얼굴과 주먹 중심, 굵은 만화선, 오렌지 배경, 글자와 테두리 없이 전체 영역 사용."
